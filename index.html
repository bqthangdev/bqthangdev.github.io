Image to Base64

Upload one or more images to convert them to Base64.

💡 Hướng dẫn sử dụng
  • Nhấn vào vùng upload hoặc kéo thả ảnh vào (PNG, JPG, GIF, WebP, SVG…). Có thể chọn nhiều ảnh cùng lúc.
  • Mỗi ảnh hiển thị kết quả riêng; chọn định dạng Base64 (chuỗi thuần) hoặc Data URL (có prefix data:image/…).
  • Nhấn Copy để sao chép hoặc Download để tải về file .txt.

Text Compare

Paste text in both panels and click Compare to see line-by-line differences.

💡 Hướng dẫn sử dụng
  • Dán nội dung vào ô Text A và Text B, sau đó nhấn Compare!.
  • Kết quả hiển thị theo dòng: nền xanh = thêm mới, nền đỏ = đã xóa, nền vàng = có thay đổi.
  • Trong các dòng thay đổi, các ký tự khác nhau được highlight thêm ở mức ký tự.
  • Nhấn Clear all để xóa toàn bộ và làm mới.

Markdown Reader

Upload a .md file or paste Markdown content to preview it.

💡 Hướng dẫn sử dụng
  • Nhấn Load .md file để tải file Markdown từ máy, hoặc paste trực tiếp vào ô bên trái.
  • Preview tự động cập nhật theo thời gian thực khi bạn nhập.
  • Chọn Side by side hoặc Below — lựa chọn được lưu trên trình duyệt và khôi phục khi tải lại trang.
  • Ở chế độ Side by side, Sync scroll (mặc định bật) đồng bộ cuộn giữa editor và preview; tắt thì mỗi bên cuộn độc lập. Nút chỉ hiện ở chế độ này.
  • Bật Focus (Side by side hoặc Below) để ẩn tiêu đề / hướng dẫn và tăng chỗ cho editor + preview (mặc định tắt). Ở Side by side, cuộn chỉ trong từng panel, không kéo trang.
  • Ở chế độ Below, phần editor mặc định thu gọn (~2 dòng); nhấn nhãn Markdown để mở rộng / thu gọn lại.
  • Nhấn Clear để xóa nội dung và reset preview.
  • Bật Memory để tự lưu nội dung editor vào trình duyệt và khôi phục sau khi tải lại trang; dùng Clear memory để xóa nội dung đã lưu.
  • Nhấn Export PDF để xuất nội dung preview ra file PDF (qua hộp thoại in của trình duyệt).

Settings

Manage theme and stored preferences for tools that use localStorage.

💡 Hướng dẫn sử dụng
  • Chỉnh Theme (Dark / Light) tại đây hoặc bằng nút ở cuối sidebar — hai nơi đồng bộ với nhau.
  • Chỉ liệt kê các tool đang lưu cài đặt vào localStorage (hiện tại: Markdown Reader).
  • Đổi View mode, Sync scroll, Focus hoặc Memory (On / Off) tại đây sẽ đồng bộ với tool tương ứng; Sync scroll chỉ có hiệu lực ở Side by side; Focus dùng được ở cả hai chế độ xem; khi Memory Off, nút Clear saved content bị làm mờ và không nhấn được.
  • Nhấn Reset all to defaults để xóa toàn bộ cài đặt đã lưu (gồm theme) và khôi phục mặc định.
